# PDF 压缩器（Android）

一款面向个人使用的离线 PDF 压缩工具，目标是无广告、无会员、无需账号。

## 已提交的第一阶段
- Android 原生项目骨架
- 简洁的日式浅色界面雏形
- 选择文件夹并递归扫描 PDF
- 扫描结果显示文件名、来源路径和文件大小
- 轻度 / 中度 / 强力选项界面
- 支持单独选择 PDF

## 接下来
1. 完成真正的 PDF 压缩引擎（包含图片重编码与压缩等级策略）。
2. 输出到所选目录下的「PDF压缩」文件夹，绝不覆盖原文件。
3. 显示压缩前后大小、节省比例与结果路径。
4. 添加历史记录、异常处理和大文件测试。

> 注意：当前是开发中的项目骨架，压缩按钮尚未执行实际压缩。请勿将当前版本当作已完成的压缩工具使用。

## 构建
使用 Android Studio 打开仓库，等待 Gradle 同步后构建 APK。当前配置使用 JDK 17、Android Gradle Plugin 8.7.3。
